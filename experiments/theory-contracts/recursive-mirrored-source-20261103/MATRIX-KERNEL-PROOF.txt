2. Explicit continuous-time matrix integration without a Markov premise
---------------------------------------------------------------------
For every ordered pair y!=x with H_yx!=0 choose a COMPUTATIONAL positive
rate a_yx>0. The deterministic default a_yx=||H_yx|| uses only H.
Set lambda_x=sum_(y!=x) a_yx and a_yx=0 for a zero block. Let X_t be
the finite-state continuous-time Markov chain with these jump rates.
The process is merely a reference representation for the source.

Start U_0=I_x on H_x. While X_t=z, evolve the rectangular carried map by
 dU_t/dt=-(H_zz-lambda_z I_z) U_t.                       (4)
At a jump z->y multiply it on the LEFT by
 J_yz=-H_yz/a_yz:H_z->H_y.                              (5)
After any path from x to y, U_t:H_x->H_y, so no equal-fiber assumption
is needed. Then
 E_x[1_(X_t=y) U_t]=K_t(y,x).                            (6)

Proof A, forward equation. Let F_yx(t) denote the expectation on the
left. A no-jump increment at y contributes
 -(H_yy-lambda_y I)F_yx-lambda_y F_yx=-H_yy F_yx.
A jump z->y contributes a_yz J_yz F_zx=-H_yz F_zx.
Thus dot F_yx=-sum_z H_yz F_zx, with F_yx(0)=delta_yx I_x.
Finite-dimensional ODE uniqueness gives F=exp(-tH), proving (6).

Proof B, path density. A path x_0=x,...,x_n=y with jump times
0<s_1<...<s_n<t has reference density
 exp[-sum_(r=0)^n lambda_xr (s_(r+1)-s_r)]
                       product_(r=1)^n a_(xr,x_(r-1)),
with s_0=0,s_(n+1)=t. Its carried matrix is
 exp[-(t-s_n)(H_yy-lambda_y I)] J_(y,x_(n-1)) ...
                   J_(x1,x0) exp[-s_1(H_x0x0-lambda_x0 I)].
Scalar rate factors cancel EXACTLY against (5); holding-rate factors
cancel EXACTLY against the lambda terms in (4). What remains is
 exp[-(t-s_n)H_yy] (-H_(y,x_(n-1))) ...
                   (-H_(x1,x0)) exp[-s_1 H_x0x0].        (7)
This is the convergent finite-dimensional Dyson jump expansion of (1).
Consequently every positive rate choice yields the SAME matrix kernel.
Choosing rates is no physical coupling, state, time or boson measure.

Convergence is elementary at a finite regulator. The Dyson expansion
has a bound C_0 exp(C_1 t) from finitely many bounded blocks. Equivalently,
finite jump rates give no explosion; for default norm rates ||J_yx||=1
and ||U_t||<=exp[t max_z(||H_zz||+lambda_z)]. There is no extension to
unbounded/infinite-fiber operators in this proof.

Arbitrary original source marks follow by inserting their full blocks
between independent Markov representations of successive intervals and
summing both coordinate endpoints. This is exactly the kernel expansion
of section 1. A non-diagonal mark is an original insertion, not a new
physical jump rule. For bounded continuous sources one may instead use
the norm-convergent original Dyson series and its usual exponential
majorant. The same boundary contraction (3) completes the thermal source.

The positive REFERENCE path chain is not automatically the physical
boson distribution. Its matrix marks can have signs/phases. A scalar
positive path measure for the physical source requires positivity of its
