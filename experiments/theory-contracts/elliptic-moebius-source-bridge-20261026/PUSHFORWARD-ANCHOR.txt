ELLIPTIC PUSHFORWARD AND THE P2 ANCHOR
======================================
26 October 2026. Bounded original source audit and exact local monodromy test.
Atlas audit frame: revision 4a17a404b58c05f460121df8.

Verdict
-------

There is an exact and useful common bundle statement. On the already present
double cover

  p:E -> P1,             E: y^2=x^4-1,

and for the already identified nontrivial Q-fixed two-torsion spin line alpha,

  p_*O_E = O + O(-2),              p_*alpha = O(-1) + O(-1).

Therefore

  V_ell := (p_*O_E/O) + p_*alpha = O(-2) + O(-1)^2.             (1)

This is exactly the holomorphic P2 anchor with splitting exponents {1,1,2},
rank 3, degree -4 and h0=0. It is a real convergence of the existing elliptic
bosonic and spin data on the same marked base. It is stronger than the earlier
observation that several constructions merely produce the number 3.

The natural connection does not agree with the original P2 flavor connection.
Its local conjugacy class at every branch mark has order 2, whereas P2 fixes an
order 3 cusp class. Thus (1) identifies the underlying holomorphic bundle only.
It supplies neither the P2 Deligne connection nor its irreducible flavor
representation. No change to AX.P2.01 or QGEO.SYM follows.

1. Why the bundle equality is exact
-----------------------------------

The prior curve calculation gives p_*O_E=O+O(-2) and, for a nontrivial
elliptic two-torsion alpha, p_*alpha=O(-1)+O(-1). See

  experiments/theory-contracts/original-admissible-source-closure-20261025/
  ORIGINAL-BASES-AND-ELLIPTIC-SPIN.txt:55-65
  SHA256 bf6b2336e24a39aef26b9907c24f033a47a8a1318f8f19ae561e4c477680ce67.

Removing the invariant scalar O from p_*O_E leaves the trace-free deck line
O(-2). Adding the full rank 2 spin pushforward yields (1). Consequently

  rank V_ell = 3,
  deg V_ell = -2-1-1 = -4,
  h0(V_ell) = 0,
  a(V_ell) = (1,1,2).

This matches the Birkhoff-Grothendieck object in P2.TYPING exactly. v491 proves
that three positive integral splitting exponents summing to four have the
unique multiset {1,1,2}; v499 types the P2 anchor as the Deligne extension
O(-2)+O(-1)^2 under its stated rank, cusp, irreducibility and unitarity
premises. The matching object is the bundle, not the parabolic weights.

2. Smallest decisive connection test
-------------------------------------

Let x=t^2 near one branch mark. The odd local function t spans the trace-free
part of p_*O_E and obeys

  dt = (1/2)(dx/x)t.

Its canonical exponent is 1/2 and its local monodromy is -1. A flat
two-torsion line alpha is locally trivial near the ramification point because
the lifted small loop contracts on E. Its pushforward has an even and an odd
sheet combination. Their exponents are 0 and 1/2 and their monodromies are
+1 and -1. Hence the natural direct-sum pushforward has, at each of the four
marks,

  residues       {0, 1/2, 1/2},
  monodromy spec {1,-1,-1},
  chi_ell(lam)   = (lam-1)(lam+1)^2,
  trace          = -1,
  order          = 2.                                      (2)

The residue trace is one per mark. Deligne bookkeeping therefore gives

  deg V_ell = -4(0+1/2+1/2) = -4,

which explains why the same underlying bundle type appears.

The original P2 local class is different. v117 fixes an exact matrix M0 with

  chi_P2(lam)=lam^3-1,
  spec M0={1,omega,omega^2},
  trace M0=0,
  M0^3=I.

Its canonical Deligne exponents are {0,1/3,2/3}, again with trace one per
mark and degree -4. The two local matrices cannot be conjugate because their
characteristic polynomials, traces and orders differ. The equality of degree
and splitting therefore cannot be promoted to equality of logarithmic
connections.

There is a second independent obstruction. The connection naturally induced
on (1) preserves the explicit rank 1 summand p_*O_E/O, so it is reducible.
v117 proves that the intended representation generated by U and M0 is the
irreducible three-dimensional standard-times-sign representation of S4. P2
uses precisely this irreducibility to obtain stability. A connection
intertwiner cannot turn the reducible pushforward representation into that
irreducible representation.

One can put another irreducible logarithmic connection with the P2 cusp class
on the same holomorphic bundle. That connection is additional data. It is not
the natural connection induced from O_E and alpha and therefore does not give
the requested source derivation.

3. A notation trap resolved
---------------------------

v117 calls (0,1/2,1/2) the harmonic diagonal and proves

  diag M0 = (0,-i/2,+i/2).

Those are diagonal entries and the associated amplitude delta=1/2. They are
not the eigenvalues of the Deligne residue. The residue spectrum in v499 and
the active P2 setup is {0,1/3,2/3}. Thus the phrase harmonic diagonal does not
repair the mismatch in (2).

4. Was the boson-spin pushforward already the original construction?
--------------------------------------------------------------------

No such identification occurs in the bounded original set requested here or
in the targeted Atlas search for the combined pushforward. The original chain
does establish the same bundle type by another route:

  four marks + rank 3 + cusp residues + unitarity and irreducibility
  -> degree -4 + h0=0
  -> O(-2)+O(-1)^2.

It does not form (p_*O_E/O)+p_*alpha. v499 explicitly separates the genus 1
Z2 pillowcase cover from the genus 2 Z3 Biswas weight cover. The denominator
of the flavor weights is 3, not the deck order 2. Its explicit decomposable
Z3 regular-representation model yields O+O(-2)^2 and is rejected as unstable.
The surviving {1,1,2} bundle is selected through stability of the original
cusp representation, not through the elliptic direct sum.

There is a canonical mathematical reason to inspect (1): both terms already
exist on the same C2 cover, the first is the nontrivial scalar deck sector,
and the second is the unique Q-fixed nontrivial spin pushforward. Removing the
trivial scalar gives exactly one plus two dimensions with no fitted degree.
There is no original physical rule in the checked sources that declares this
boson-spin direct sum to be the generation carrier or couples its natural
connection to the flavor field. v499 records this precise module
identification as residual R1. Therefore selecting both terms as one physical
module would still be an added premise.

5. Executable finite certificate
--------------------------------

The comparison was replayed with exact SymPy arithmetic and no floats:

  M_ell = diag(-1,1,-1)
    trace=-1, det=1,
    charpoly=(lambda-1)(lambda+1)^2,
    M_ell^2=I, M_ell^3!=I.

  M0 = the exact v117 matrix
    trace=0, det=1,
    charpoly=(lambda-1)(lambda^2+lambda+1),
    M0^2!=I, M0^3=I.

  sum{0,1/2,1/2}=sum{0,1/3,2/3}=1,
  -4 times either sum = -4.

This is the smallest decisive test. It retains the positive bundle match and
excludes the stronger connection identification before any new model is built.
