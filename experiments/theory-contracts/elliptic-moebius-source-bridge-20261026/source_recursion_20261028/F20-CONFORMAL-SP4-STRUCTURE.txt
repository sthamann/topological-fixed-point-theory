1. Alle alternierenden Formen
-----------------------------

Fuer die unveraenderten v419 Matrizen

  C=C5,   G C G^-1=C^2

ist der Raum der C invarianten alternierenden Formen genau zweidimensional.
Eine ganzzahlige Basis ist

  A = [ 0  0  1 -1]       B = [ 0  1  0  0]
      [ 0  0  0  1]           [-1  0  1  0]
      [-1  0  0  0]           [ 0 -1  0  1]
      [ 1 -1  0  0],          [ 0  0 -1  0].

Auf diesem Formenraum wirkt G durch

  G*(A)=B,   G*(B)=-A,

also mit Matrix [[0,-1],[1,0]]. Die beiden Eigenformen sind

  Omega_+ = i A+B,       G^T Omega_+ G = +i Omega_+,
  Omega_- =-i A+B,       G^T Omega_- G = -i Omega_- .       (1)

Beide sind nicht ausgeartet:

  rank Omega_+=rank Omega_-=4,
  det Omega_+=3-4i=(2-i)^2,
  det Omega_-=3+4i=(2+i)^2.                               (2)

Damit liegt das originale F20 nicht nur in GL4. Es liegt exakt in CSp4 mit
Similitudencharakter

  chi(C)=1,   chi(G)=i                                  (3)

fuer Omega_+; Omega_- liefert den konjugierten Charakter.

2. Der zentrale mu8 Lift
------------------------

Setze zeta8=exp(pi i/4) und

  Ghat=zeta8^(-1) G.

Dann gilt exakt

  Ghat^T Omega_+ Ghat=Omega_+,
  Ghat C Ghat^-1=C^2,
  Ghat^4=-I,   Ghat^8=I.                                 (4)

Der notwendige zentrale Faktor ist also kein frei optimierter Parameter.
Er ist die Quadratwurzel des inversen Similitudencharakters:

  zeta8^(-2)=chi(G)^(-1)=-i.

Dies ist die Spin5 gleich Sp4 Hebung der cyclotomischen F20 Wirkung. Die
Rohwirkung G hatte Ordnung4; die symplektisch normalisierte Wirkung hat
notwendig Ordnung8.

------------------------------------------------

In Lambda2(V) spannt der inverse symplektische Bivektor eine Linie mit
Charakter chi. Nach Quotient und Normalisierung entsteht

folgt ebenso elementweise

fixiert die saubere strukturelle Konvention (7).
