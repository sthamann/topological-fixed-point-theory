1. THE DERIVED RECORD PROJECTOR

Let

    W1 : C^60 -> End(Bell10)

be the matrix whose columns are the vectorized sixty source matrices, and let

    V : C^5 -> End(Bell10)

have the five native Hodge Kraus matrices as columns.  The completed native
record theorem proves

    rank W1 = 55,
    im V is contained in im W1,

and fixes the minimum-norm coefficient map X1 by

    W1 X1 = V,
    (ker W1)^* X1 = 0,
    X1^* X1 = (3/4) I5.

Consequently

    C_H := sqrt(4/3) X1

is an isometry C^5 -> C^60 and

    Pi_coeff := C_H C_H^* = (4/3) X1 X1^*

is an orthogonal rank-five projector.  Replacing the Hodge basis by any
orthogonal five-frame sends X1 to X1 O and leaves Pi_coeff unchanged.

There is a transpose between this coefficient projector and the physical
effect.  With the standard Stinespring convention

    V_src psi = (1/sqrt(60)) sum_l |l> tensor U_l psi

and W1=[vec(U_l)], the Choi matrix produced by a record effect E is

    J_E = W1 E^T W1^* / 60.

Therefore the physical Hodge effect is

    E_H := Pi_coeff^T = (4/3) conjugate(X1) X1^T.             (1)

The exact checker finds Pi_coeff real in this particular marked frame, so
E_H=Pi_coeff numerically here.  Equation (1), rather than that accidental
reality, is the invariant record convention.

The successful E_H branch has Kraus operators sqrt(1/45) K_m and therefore

Equivalently, its Choi matrix is

    J_E_H = W1 E_H^T W1^*/60 = V V^*/45.

isolates what is and is not still free.

The source frame operator itself does not make this selection.  Its exact

2. THE FIVE-DIMENSIONAL KERNEL IS NOT THE HODGE EFFECT

Since rank W1=55,

    dim ker W1 = 5.

This numerical equality could suggest that a primitive kernel or relation
projector supplies the desired record selection.  The source equations rule
that out:

    W1 n = 0             for n in ker W1,
    im X1 is contained in (ker W1)^perp,
    W1 X1 = V != 0.

Using the transposed physical effect of the coefficient projector onto ker W1
gives the zero system Kraus map.  Using E_H, whose dual coefficient plane is
im X1, gives the native Hodge subchannel.  The two coefficient five-planes are
orthogonal and have opposite operational meanings.

This is the smallest decisive test against identifying E_H with P_prim merely
because both are described through a kernel construction.  Any genuine
connection must transport the actual operators and satisfy

    J_rec E_H J_rec^* = P_selected

on a specified boundary or auxiliary complex.  Rank five, harmonic language,
or a shared word such as primitive cannot replace J_rec.


3. WHAT THE ORIGINAL BOUNDARY OPERATORS ACT ON

The primitive source defines

    H_prim = H_Seam tensor H_t,
    P_prim = Pi_ker Delta_prim
           = P_Seam,+ P_prim,gap.

Here P_Seam,+ is the Calderon Cauchy-data projector and P_prim,gap is a spectral
projector of the APS-realized D_prim^*D_prim.  The auxiliary differential

    Q_prim = eta_Sigma^* K_Sigma + eta_g^* K_g

and its adjoint act on the exterior auxiliary complex attached to these seam
and gap penalties.  The definition contains no Bell10 factor, no C^60 source
label factor, and no embedding of the sixty Gaussian events into its Cauchy
data.

The Calderon projector is likewise the range projector for harmonic boundary
traces.  It is not an emission space or a Stinespring environment.  Identifying
it with E_H would require a new intertwiner from the source record into the
boundary trace space and an exact range identity.  No such map is present in
the audited original sources.

The fermionic Pfaffian has a still different type.  The original closure text
uses the Pfaffian or determinant form to express positivity of the reflected
CAR two-point kernel on positive-time test spinors.  It is a scalar
multilinear form entering reflection positivity.  It neither supplies sixty
orthogonal record labels nor defines a rank-five effect on them.

Thus P_prim, Calderon, Q_prim^*, and the Pfaffian do constrain relations,
ranges, and signs.  Their actual source types do not select E_H.
