Use the actual 60 Gaussian E8 source reflections U_l on Sym^2(C^4), and the
five original epsilon matrices C_m on Lambda^2(C^5), with the six already
constructed mark-dependent Bell/duad charts W_q. The unnormalized Choi

 J60=(1/60) sum_l |U_l>><<U_l|,  rho60=J60/10,
 P5=(1/6) sum_m |C_m>><<C_m|,    rhoH=P5/5.

For every one of the six original charts, the source checker calculates

 sum_l,m |Tr(C_m^* W_q^T U_l W_q)|^2 = 144,
 Tr(P5 rho60 in chart q)=144/(6*60*10)=1/25,
 Tr(P5 rhoH)=1.

Thus this explicit prepared maximally entangled input and P5 measurement
separates the two channels by 24/25 in probability. The usual convention
for the half diamond distance gives distance >=24/25 in these six charts.
This is not the earlier marked normalized twenty-jump process, where the
same P5 probability was 1/5. P5 is a valid internal operator; its realization
as an allowed physical preparation and measurement remains a separate source
question, as does the actual chart's operator and state correspondence.

The conclusion also does not depend on choosing these charts for the weaker
bound: the normalized Choi eigenvalues of the 60 channel are 4/25 once,
2/75 nine times, 1/75 45 times, and 0 otherwise. The original 60x60 Gram
matrix is integral. The checker verifies its annihilating polynomial
x(x-8)(x-16)(x-96) and trace moments 600, 14400, 944640, which uniquely
fix multiplicities 0^5, 8^45, 16^9, 96^1. Dividing by 600 yields the
Choi eigenvalues.

Under ANY unitary identification of the ten-dimensional input and output
spaces, rho60 is unitarily conjugated on the Choi tensor product and retains
these eigenvalues. By the Ky Fan variational inequality, for any orthogonal
rank-five projector P,

 Tr(P rho60) <= 4/25+4*(2/75)=4/15.

Since rhoH is supported on P5, the maximally entangled input followed by
P5 yields half diamond distance >= 1-4/15=11/15, uniformly for all such
unitary input and output identifications. This is a lower bound, not a claim
of the exact optimal channel distance. The stronger 24/25 holds in the six

CLASSICAL RECORD SELECTION DOES NOT GENERATE THE HODGE EVENT
-----------------------------------------------------------
Let a nonzero classical selection of the original recorded unitary events
have CP map E(X)=sum_l w_l U_l X U_l*, w_l>=0. If E=p Phi_H for p>0,
its Choi support is span{|C_m>>}. A positive sum of rank-one projectors has
support equal to the span of all its positively weighted vectors, so every
U_l with w_l>0 must lie in span{C_m}. The original R088 builder proves every
nonzero combination sum z_m C_m has rank exactly 6, whereas each U_l is
unitary of rank 10. Contradiction. Fixed invertible/unitary input and output
identifications preserve ranks and do not change this argument.

The same argument applies to positive classical selection of finite record
histories when every selected history is a product of the original unitaries:
each such product is still rank 10. It does not apply if the source supports
an additional nonunitary instrument, coherent manipulation, a modified
record/environment, or an intervention before or between the original
unitaries. A refinement of an individual unitary channel that averages back
to exactly that SAME channel can only use Kraus operators proportional to the
unitary, by rank-one Choi support. The existing marked stay/jump instrument
is consistent with this: its refinement preserves the unmonitored channel
after averaging the source labels, not for each individually fixed label.
The actual original seam must decide whether and how such a refinement and
recording are realized. No independent event rate or measurement is assumed.
