fibre sum, followed by the original endpoint contraction. For explicitly
supplied original atoms x it computes

All four matrices are integrated BEFORE the connected subtraction.
Their Gram form can be nonorthogonal or have null classes. The code uses
a declared numerical eigenvalue threshold for its retained quotient and
transports every supplied form. This is an approximation without a
certified original null ideal or rank gap; the threshold and eigenvalues
are returned. It then
keeps P exactly twice at the outer boundary. No P is inserted between
letters, no scalar/reference is set to one, and no conditional per-field
normalization is used. Supplied complex/signed weights are retained.
The second supported input is an already integrated whole blocked kernel;
it follows the identical endpoint contraction. This is a consumer and an
aggregation implementation, not the missing physical producer.

Eighteen end-to-end arithmetic controls passed, including a complex cap,
noncommuting P, nonorthogonal Gram with null class, complex unnormalized
atom weights, and equality between direct whole-kernel contraction and
the fibre sum. A null class cannot acquire a marked value. Missing
weights/reference/source data have no unit fallback. Empty input and a
role string cannot enable a full physical start. These controls are
labelled ARITHMETIC ONLY and are not physical TFPT parameters or values.
physical_source_complete is always false for this consumer; a metadata
label cannot certify the original source identity. numeric_bundle_ready
and direct-caller readiness report an actually validated and evaluated

The source now separates direct whole-caller evaluation from field fibres.
evaluate_source consumes a supplied whole endpoint source or finite fibre
sum. contribution_capability_report and evaluate_contribution expose
unnormalized W0,WU,WY,WUY matrices and the ORIGINAL measure mass separately.
The native unit either contains the whole history and both boson endpoints,
or is an original retained-field fibre whose packet already retains them.
The physical P remains outside the eventual aggregate, never P_H.

integration_plan enumerates every supplied original measure atom. Its
unit multiplicity counts that actual atom once; it does not replace its
supplied measure mass by1. Two distinct actual atoms having the same
visible field genotype remain two entries. aggregate_contributions accepts
the full original atom set, sums its actual masses and matrix packets,
and only then forms Z0,ZU,ZY,ZUY and their connected quotient. A partial
archive is not a whole Z. Genetic fitness and deduplication never become
physical probabilities. No new Monte Carlo proposal was introduced.

The contribution path was tested against the direct original-form sum
on the visibly arithmetic-only fixture, including two atoms with the same
visible configuration and a rejected partial archive. These are program
checks, not an integration of physical Higgs configurations.
