# Executable source construction programs

The registry searches weighted source constructions. A candidate changes the scalar body and all even kernel coefficients, rather than supplying another numerical Higgs configuration. It uses the original coherent kernel, finite nilpotent exponential, Berezin sewing and coherent trace implementations directly.

`registry_operations()` returns trusted operation dictionaries with `id`, `input_types`, `output_type`, `execute` and an original dependency SHA in `version`. Outputs carry no physical completion flag. The root verifier decides the declared goal and checks the original source, mark, time, constraint and limit identities.

The original interface supports an explicitly identified retained chart of one through five CAR modes. This is an implementation scope, not a universal requirement on primitive TFPT. Its unintegrated or eliminated inner fields cannot be discarded by calling this a full physical construction.

The smallest executable path is:

```text
KernelActionProgram
  -> native.nil_action
EvenSourceOperator
  + WholeSourceDictionary
  -> native.source_jets
WholeSourceCandidate
```

`KernelActionProgram` contains `modes`, `mode_chart_id`, `body`, `nil_action`, `source_symbols`, and optional `hypotheses` and `provenance`. `body` and each even Grassmann coefficient are exact SymPy expressions generated by the trusted typed scalar operations. `nil_action` is a sparse mask dictionary in the original ordering of barred variables followed by fields. Its body is zero because the absolute scalar is searched separately. Higher interactions are retained. The separate `native.even_kernel` constructor also accepts kernels whose scalar body vanishes and does not divide by that body.

`EvenSourceOperator` contains the actual symbolic weighted `matrix`, chart and mode labels, both formal source symbols, hypotheses and provenance. `native.sew` evaluates the original ordered Berezin integral and returns the product kernel. It does not replace a retained block by an assumed semigroup or a guessed Hamiltonian.

`WholeSourceDictionary` must explicitly supply `P`, `cap`, `reference_scalar`, `outer_scalar` and dictionary bindings for `P`, `cap`, `reference`, `absolute`, `time`, `U`, `Y`. Each binding declares its role as original, hypothesis or arithmetic control. There are no unit projector, state, cap, normalization, time or reference defaults. Factors depending on the marked sources must already occur inside the whole marked kernel before differentiation.

`WholeSourceCandidate` contains:

- `matrix`, `modes`, `mode_chart_id`, `source_symbols`;
- `ordered_source_forms` with actual matrices `Z0`, `ZU`, `ZY`, `ZUY` obtained from the whole kernel and its first mixed source jet;
- four exact common unnormalized scalar values under the explicit cap, outer selector and reference;
- normalized `U`, `Y`, `UY`, `connected_UY` when the same zero-source denominator is nonzero;
- the literal `dictionary`, its `bindings`, all declared `hypotheses`, `provenance` and the conditional construction `scope`.

The exact contraction is performed by the original `coherent_trace`, with the whole outer product `cap P Q P`. There is no extra projector between source letters. A singular zero-source program is rejected locally and does not halt the synthesis of other programs.

## Search grammar

The registry has twenty operations. Scalar leaves include the actual original `c3=1/(8π)` and the given C6 ratio `64/729`, plus the mathematical coefficient ring unit and complex unit. Using the coefficient ring unit in an explicit candidate body is a proposed source relation, never a physical normalization default. Addition, multiplication, negation and division generate exact scalar programs; division by zero is rejected. The two formal source variables are available through typed operations.

For each supplied original mode chart, enumerate its finite even masks as `EvenGrassmannMask` inputs. `native.monomial`, `native.kernel_add`, `native.action_from_polynomial`, `native.nil_action` and `native.even_kernel` then enumerate arbitrary finite even kernel or action programs over the generated coefficient ring. At fixed mode count this covers the even operator coefficient space when its scalar coefficients are available. It is not a completeness theorem for an unspecified infinite field source or for every possible transcendental coefficient function.

The concrete `native.quartic_source_program` template provides an executable nonGaussian family with a searched body and quartic coefficient. Its sources mark coherent bilinears in the kernel action. They are not automatically physical endpoint occupations, the HYPF norm, or the Hamiltonian Yukawa mark. These assignments remain explicit hypotheses in every candidate.

Where actual endpoint operators exist, `native.endpoint_marks` instead constructs the complete marked source `(I+jY Y) K (I+jU U)` with the explicitly supplied initial/final placement and time binding. Its mixed source form is exactly `Y K U`. No time generator or semigroup is selected.

A directly executable AST uses `native.c3` as body, `native.c6_ratio` as quartic coefficient, an explicitly supplied `ModeChart` and `SourceSymbolPair`, followed by `native.nil_action` and `native.source_jets` with an explicitly supplied dictionary. The scalar seeds are original results; the functional relation assigning them to this new source program is a hypothesis.
