1. Hypotheses on the SAME original Hilbert space
------------------------------------------------
Let H be a complex Hilbert space, B a self-adjoint operator on H and u a
unitary operator on H. Assume:

 (H1) Strong time covariance, for every real t,

      exp(itB) u exp(-itB) = exp(it) u.                  (1)

 (H2) 0 is not in the spectrum of B.

 (H3) With P_B = 1_(0,infinity)(B), the compression

      S = P_B u P_B : P_B H -> P_B H

      is Fredholm and ind(S) = -1.

Units are chosen so that the shift in (1) is one. If the actual source uses a
positive shift omega, the rescaling B/omega must be declared and justified
using that same source; this is not a choice of a new physical clock.

Conclusion: for exactly one epsilon in (0,1), the pair is unitarily equivalent
to

      H = L2(S1,dtheta/(2 pi)),
      B = -i partial_theta + epsilon,   Dom(B) = H1(S1),
      u = multiplication by exp(i theta),
      P_B = projection onto the Fourier modes n >= 0.    (2)

The canonical primitive seam line is

      Pi = P_B - u P_B u* = 1_(0,1](B),
      rank(Pi) = 1.                                   (3)

Choosing a unit vector psi in this line only fixes an irrelevant common phase
for the basis u^n psi. Both Pi and every subspace in the construction are
independent of that phase. The conclusion classifies this operator class;
it does not assert that every primitive TFPT boundary must satisfy (H1)--(H3).

2. Domain-safe covariance and the compression
---------------------------------------------
From (1),

      u* exp(itB) u = exp(it) exp(itB) = exp(it(B+1)).

Uniqueness of the self-adjoint generator implies

      u Dom(B) = Dom(B),
      u* B u = B+1,
      B u xi = u(B+1)xi       for xi in Dom(B).          (4)

Thus the spectral functional calculus gives, for every Borel set Delta,

      u E_B(Delta) u* = E_B(Delta+1).                   (5)

In particular,

      u P_B u* = E_B((1,infinity)) <= P_B.              (6)

Therefore u leaves P_B H invariant and S is simply u restricted to P_B H.
It is an isometry, with

      S* S = I_(P_B H),
      S S* = E_B((1,infinity))|_(P_B H).

The defect projection in (3) is consequently an orthogonal spectral
projection. A formal commutator [B,u]=u on an unspecified set of vectors is
not a replacement for (1) or a proven equivalent common-core theorem.

3. The index constructs the line, with its sign fixed
----------------------------------------------------
An isometry has zero kernel and closed range. Hence

      ind(S) = -dim ker(S*) = -rank(Pi).

Hypothesis (H3) yields rank(Pi)=1. Since Pi is a rank-one spectral projection
on the bounded interval (0,1], its range lies in Dom(B), and B acts there by
one scalar epsilon with 0 < epsilon <= 1. Let psi be any unit vector in it:

      B psi = epsilon psi.

The endpoint epsilon=1 would give B u^(-1)psi=0 by (4), contradicting (H2).
Thus 0 < epsilon < 1.

The sign in (H3) is the usual Hardy orientation: multiplication by z has
zero kernel and a one-dimensional cokernel on the nonnegative Fourier modes.
An oppositely oriented original seam must be paired with u* and the
correspondingly reversed spectral-flow convention. An orientation convention
cannot supply the missing relation between B and u.

4. Completeness on the original H, not an added model space
----------------------------------------------------------
Define e_n=u^n psi for all n in Z. Equations (4)--(5) imply

      B e_n = (n+epsilon)e_n,
      E_B((n,n+1]) = u^n Pi u^(-n).                    (7)

These projections have pairwise orthogonal ranges and each has rank one.
Since the half-open intervals (n,n+1] partition the real line, countable

      sum_(n in Z) E_B((n,n+1]) = I    strongly.         (8)

Consequently {e_n:n in Z} is an orthonormal basis of the ENTIRE H. There is

        = {sum c_n exp(in theta): sum |n+epsilon|^2 |c_n|^2 < infinity}

      W B W* = -i partial_theta+epsilon.                (9)

This proves (2), including the unbounded operator domain. Compact resolvent,

9. Why winding and the existing offset cannot supply the covariance
-------------------------------------------------------------------
The distinction persists inside a fixed circle Hilbert space with a fixed
quarter-shifted B, without changing its CAR state. Put

      B=-i partial_theta+1/4,
      b_a(z)=(z-a)/(1-a z),  u_a(z)=z^2/b_a(z), 0<a<1/3.

The unimodular smooth u_a has winding 2-1=1. Its angular derivative is

      d arg(u_a)/dtheta = 2-(1-a^2)/|exp(i theta)-a|^2 > 0,

because the maximum of the subtracted Poisson kernel is (1+a)/(1-a)<2.
Nevertheless

      u_a* B u_a-B = d arg(u_a)/dtheta

is nonconstant. Hence (H1) fails while the winding and quarter offset agree.
With the same Hardy cut, the negative Fourier coefficients of u_a are
(1-a^2)a^(m+1) at z^(-m), m>=1. Thus

      ||(1-P_B)u_a e_0||^2 = a^4(1-a^2) > 0.

At a=1/4 this equals 15/4096. The Toeplitz index remains -1 by its actual
circle-symbol pairing, but the compression is not an isometry. This is a
counterexample to inferring (H1) or isometry from that index/winding/offset
alone. It is not a pair of complete TFPT models and does not exclude an
additional original source rule which identifies the correct representative.
