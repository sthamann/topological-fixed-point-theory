2. WHICH UNITARITY IS ACTUALLY PROVED

The positive flat metric in row coordinates is

It obeys G^dagger H G=I. The normalized fundamental matrix instead obeys

 Psi(z)^dagger H(z) Psi(z)=Hbase,
 Hbase=Gbase^-dagger Gbase^-1.

Thus Psi is an isometry from the fixed BASE metric to the variable row
metric, not an H(z)-unitary endomorphism of the same metric fiber.
Setting C=Hbase^-1/2 gives an H-orthonormal flat frame F=Psi C, but

 det F=det(C)(1-z^4).

Any other flat orthonormal frame differs by a constant unitary, so it
has the same nonconstant determinant modulus up to a constant. On a

It is not the determinant of an ordinary SU3-valued matrix in the retained
row coordinates. In particular det Psi(1/2)=15/16, not a unit modulus1.

4. THE RADIAL NORMALIZATION/CONNECTION TERM DOES NOT VANISH

For the holomorphic original frame, z=rho exp(i theta),

 partial_rho Psi=exp(i theta) A(z) Psi,
 partial_rho log det Psi
   =-4rho^3 exp(4i theta)/(1-rho^4 exp(4i theta)).

At theta0,rho=1/2 the latter is exactly -8/15, not zero. The constant
orthonormalization C does not remove this derivative. The norm's radial
variation is also visible in det H=|det G|^-2. Consequently a rho-dependent
isometry cannot simply be pulled through a radial derivative as though
it were constant. If f=F^-1 psi, then

 F^-1 partial_rho psi=partial_rho f+(F^-1 partial_rho F)f.

For the ACTUAL flat covariant radial derivative partial_rho-exp(i theta)A
the two terms cancel, as they should under a legitimate frame change.
If the given collar instead uses a different product normal derivative,
its actual connection and identification r versus rho must be supplied.

For a single fixed rho it is possible to extend the frame as constant
in an independent collar coordinate r, in which case that partial_r is
unchanged. This is an extension/identification to check against the
original collar and its two faces, not a consequence of the circle
trivialization. No claim that every extension is impossible is made.

Similarly, under a rho-dependent conjugation T_rho -> I_rho T_rho I_rho^-1,
the derivative includes [(partial_rho I_rho)I_rho^-1, T_image]. A claimed
unchanged radial source response must account for it and for transported
insertions, state and declared reference. If all these are transported
covariantly, a cancellation may be genuine; it is not proved by calling
the single-particle map unitary.

An actual endomorphism coefficient also transforms: Phi_flat=F^-1 Phi_row F

condition. Conversely a coefficient already specified in the horizontal
frame must not be mistaken for the same constant row matrix. This is a
coordinate/source dictionary check, not an exclusion of either valid case.
