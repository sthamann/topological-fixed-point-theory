2. The first C57 identification, tested on the actual OS unit
At one fixed original system write omega_rel for the functional used in
its OS form, and N=omega_rel(1)>0. Translation on its observable algebra
is unital: tau_t(1)=1. Consequently
  T_t[1]=[1],
  ([1],T_t[1])_OS=N,
  Omega=[1]/sqrt(N), H_adm Omega=0,
  <Omega,exp(-t H_adm)Omega>=1.
If omega_rel is the raw generating functional, N=Z_rel[0]. If the original
Schwinger functional is normalized separately, N=1. Either convention
gives a t-independent unit matrix element. The ratio alone must not be
silently conflated with a separately normalized state convention.

This is a fixed-system time test. Varying the collar geometry ell, hence
the functional omega_ell and its unit norm N_ell, is a different operation.
N_ell can vary. The test does not prohibit a separately established
identity Z_rel[0;ell]=det_F C(ell); it shows that F=G=1 and OS translation
do not establish that identity or its parameter derivative.

For the given coupled source, its old sea Omega0 is a definite vector in
the same Fock representation as the coupled sea Omega_h. With coupled
excitation energy H_exc>=0 and H_exc Omega_h=0, the established identity is
  A_cap(ell)=<Omega0,exp(-ell H_exc)Omega0>=det_F C(ell).
For each existing odd singular pair C_p=a_p+(1-a_p)exp(-2ell E_p),
  a_p=(1+|p|/E_p)/2, E_p=sqrt(p^2+m_p^2).
For ell>0 the exact distinguishing response is
  A_cap'(ell)=-||H_exc^(1/2)exp(-ell H_exc/2)Omega0||^2.
It is strictly negative if an actual nonzero pair mass excites Omega0.
The derivative at ell=0 is not asserted: the old vector can fail the
coupled energy form domain there. No extra conjugate-pair count is added.

Thus Omega0 is generically not the OS unit vacuum for a system whose
Hamiltonian is identified with this H_exc. At Phi=0 the two seas agree,
so the unit test alone cannot distinguish their common trivial amplitude.
C57's constant-pair derivative in u=m^2/k is a valid CAP derivative:
  -partial_u log A_cap|_0
    =sum_(actual p,pair j) k_j(1-exp(-2ell|p|))/(4p^2).
It has not thereby become a derivative of the original Z_rel or MASTER.

4. The positive original caller and the actual boundary-vector question
The original translation construction gives, for its actual positive-time
admissible insertion classes,
  ([F],T_t[G])_OS=omega_rel(Theta F tau_t G).
After state normalization this expression is divided by N. This is the
existing caller for both boundary insertions, reflected products and time;
there is no need to invent another state for the full operational Seed.
The cap could enter this caller if an actual source map identifies
  [F0]/||[F0]|| <-> Omega0, H_adm <-> H_exc,
with the same original reference, domain and boundary conditions. Then
its proper call is F=G=F0, not automatically the unit. More generally a
specified source boundary functional can supply that vector without a
single polynomial representative. Density of OS polynomial vectors alone
does not identify a particular F0, its locality or its admissibility.

Neither Q2:256-264 nor Q8:143-151,217-255 specifies old Phi=0 APS sea
boundary data as such an insertion or equates Z_ref[0] with this vector.
The targeted search in these QFT/boundary sources found no such explicit
Omega0 cap call. This is the scope of the read, not a corpus-wide absence
claim. A quotient by a scalar reference partition function is not itself
that missing boundary-vector identification.

For W_rel=log Z_adm[J;xi]-log Z_ref[0;xi], source independence implies
  delta_J^n W_rel=delta_J^n log Z_adm, n>=1.
The actual normalized generating functional satisfies exactly
  Zhat[J;xi]=Z_rel[J;xi]/Z_rel[0;xi]
            =Z_adm[J;xi]/Z_adm[0;xi].

difference of negative expected action variations. If those data move,
their original measure, projector/domain, chi, reference and eta responses
must also be included. No field-independent addition is selected here.
