R096. Joint Higgs, original quark and two-face source: conditional identities

Scope and provenance
--------------------
This is a strengthening and connection of the existing R054 color-singlet
four-word result and the previously observed failure of a pure averaged
projector (REGIONAL-SOURCE-PARTNER-PROOF.txt, section 8). It is not a second,
independent physical observation. Use the original v252 full 96 constructor,
the fixed quarter mode, the given Yukawas and the actual two-face covariance
of ACTUAL-ONEFORM-COUPLED-SOURCE-RESPONSE.txt. The latter is a fixed-H source.
The original Z_adm and Z_rel are formal source contracts; the complete
interacting Higgs pushforward, conditional fermion state, face transport and
its positivity are not identified by this calculation.

1. Quantitative bound on the same two-face carrier
-------------------------------------------------
Let mu be a positive normalized Higgs weight. On ONE common two-face CAR
space, suppose each conditional one-particle covariance P_H is selfadjoint
with 0 <= P_H <= 1. Set Pbar = integral P_H dmu and let L be the fixed rank 6
projector on one color and the six left-quark modes of the second face.
Let m(H)=Tr(L P_H L). Direct expansion gives the operator identity

 Pbar-Pbar^2 = integral (P_H-P_H^2) dmu
               + integral (P_H-Pbar)^2 dmu.

The first term is nonnegative by 0 <= P_H <= 1, the second is an average of
operator squares. For X=P_H-Pbar, Hilbert-Schmidt Cauchy-Schwarz gives

 Tr(L X^2 L) >= (Tr L X L)^2 / 6,
 Tr L(Pbar-Pbar^2)L >= Var_mu(m)/6.                         (1)

Using the existing R054 result, additionally assuming its actual constant-H
color-symmetric, conditional quasifree fermion fibers and the same weights,
the color-singlet four-word Wick defect is Delta_O=24 Var_mu(m). Hence

 Tr L(Pbar-Pbar^2)L >= Delta_O/144.                        (2)

Writing Pbar=[[A,X],[X*,C]], the left side is
Tr L(C-C^2-X*X)L, with L now on the second face. Thus (2) connects the full
two-face crossing, the single-face response, and the four-word defect on the
same carrier. If Var(m)>0, Pbar cannot be a projection. This was already
known qualitatively; the rank-six lower bound makes the relation quantitative.
It does not rule out a pure primitive state before H is integrated out.

2. Linear mixed-source identity without positivity
--------------------------------------------------
For the same R054 conditional fibers, O=3N^2-sum_cd E_cd E_dc obeys
<O>_H=24m(H)^2 and <N>_H=3m(H), with the stated color symmetry. Therefore,
for the same integrable unnormalized weight on both sides,

 Z[O] = 8 Z[m(H^dagger H) N].                              (3)

The identity is linear and does not require positivity of the weight.
It requires the mixed insertion m(H^dagger H)N and the stated conditional
fiber identities. It cannot be added to the original solver alphabet until
the original H carrier, source insertion, and conditional fibers are actually
connected. With normalized positive mu, (3) recovers Delta_O=8 Cov(m,N),
so the mixed word and the quartic defect express the same relation, not two
independent measurements. Finite or complex normalization is not presumed.

3. A second mixed source word reading the actual crossing block
---------------------------------------------------------------
On the original 36-dimensional quark particle module Q, use the two-face
cross block X_H=(2 cosh(ell h_H))^-1 at fixed constant H, h_H^2=p^2+Phi_H^2.
With a shared real face frame, define

 B_Q = (1/2) sum_{a in Q}(a^dagger_{left,a} a_{right,a}+h.c.).

The two face labels are not the internal L/R chiralities. Put u=H^dagger H,
and y_j the six given quark Yukawa singular values. Then

 g(u)=<B_Q>_H=Tr_Q X_H
     =6 sum_{j=1}^6 [2 cosh(ell sqrt(p^2+y_j^2 u))]^-1. (4)

Each of six singular values has multiplicity 3 colors times 2 chiralities.
For ell>0, p>0 and at least one y_j nonzero, g is strictly decreasing on
u>=0. For f(u)=u/(1+u), any positive normalized mu with nonconstant u gives

 Cov_mu(f,B_Q) = (1/2) integral integral (f(u)-f(v))
                            (g(u)-g(v)) dmu(u)dmu(v) < 0.  (5)

If mu assigns masses m_A,m_B to [0,a] and [b,infinity), 0<=a<b, then
Cov_mu(f,B_Q) <= -m_A m_B [f(b)-f(a)][g(a)-g(b)]. Both f and B_Q are
bounded for this finite carrier. A common unitary frame transformation on
both faces leaves B_Q invariant. Independent face gauge transformations
require the actual transported identification; no Wilson bridge is assumed.

The real face chart, inclusion of the conditional H fibers in the same
original source, all further vertices, reference/eta/Z0, H-dependent weights,
and comparison with the primitive P1 source remain to be established. In
particular no actual Higgs probability or nonzero H fluctuation follows here.
The finite constant-H slice alone says nothing about generic H(x) measures.

4. Reproducible controls
------------------------
Run python3 -B check_joint_higgs_twoface_response_20261102.py. It evaluates
the full original 96 matrix and the 192-dimensional two-face projector for
four diagnostic Higgs values, including two weak directions at equal u;
checks (4), monotonicity and (1); and independently checks equality of the
rank-six bound in a rational abstract covariance example. The seed252 Yukawas,

derived TFPT measure. The old exact Fock proof remains the evidence for the
R054 four-word formula; the new script does not re-prove it from CAR matrices.
