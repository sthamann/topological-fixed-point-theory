7.3 The actual self-duality leg and its one remaining phase

For J_E(v)=D_E bar(v), a symmetric form B=cI is E0-real precisely when

  B(J_Ev,J_Ew)=bar(B(v,w))

  D_E^T B D_E=bar(B),  c omega=bar(c).                        (14)

Thus the real-type representation does permit a repair. Equation (14) fixes

  c=exp(-i pi/3)

works; equivalently c=-omega. With such an E0-real b:F->F^*, set

  K=H B^(-1) : F^* -> F.

Equation (14) implies

  D_E^(-1)B^(-1)=bar(B)^(-1)D_E^T,

and therefore

  K^E=H^E B^(-1)
     =D_E bar(H)D_E^(-1)B^(-1)
     =D_E bar(K)D_E^T.                                     (15)

Thus converting H by the E0-real b leg makes the Hom and bilinear
transformation rules exactly equivalent. If instead B_0=I is held
fixed in the displayed signed frame, E0 transports it with the nontrivial

The decisive source question is therefore no longer whether a self-duality

9.3 What v561 actually proves

The v561 checker explicitly labels itself a narrowing result. It inserts

  RHO=exp(i pi/3)                                             (27)

as a declared constant and checks the arithmetic identity

  sum_(d in {2,8,12,14,18,20,24,30}) RHO^d = 4 RHO.          (28)

It then finds two inequivalent scalar diagnostics,

  P2=arg(sum RHO^d),             character (-1,+1),
  V5=Im(RHO det)/det,            character (-1,-1).           (29)

Neither (28) nor (29) is a state, an insertion, an operator on the E8
adjoint, or an expectation value. The checker says that neither carrier is
frame-coupled and leaves the physical choice open. In particular, (28) is
not an E8 adjoint trace merely because the summation indices are E8 degrees.

9.4 Typing against the actual whole F5/96 source

The finite source checker fixes

  H_F=C^96=(particle/antiparticle) x (three generations) x C^16

and builds the complete D_F from 3 by 3 generation matrices Y and the
Majorana block, together with the actual J_F, grading and face data. It does
not define U6, RHO, K_f^str, a representation C6 -> End(H_F), an embedding of
the six phase sites into the generation/particle slots, or an observable O
whose expectation is P2 or V5. Its displayed Y matrices are structural test
inputs; they are not obtained from (18)-(26).

Therefore the already fixed full source state and time evolution cannot yet
measure rho: the operator to evolve and the typed consumer to read are
absent before any state or time question arises. Although C^96 can of course
host many six-dimensional subspaces, choosing one would be a new phase-fiber
embedding rather than a consequence of the original source.

9.5 Verdict and first missing definition

No original rho-carrying operator insertion or response functional on the
actual full F5/96 source was found. The explicit Kstr path is a positive,
orientation-even magnitude consumer. The bare closed v117 triangle remains
real by Section 8. The v561 identity 4 RHO is a scalar character sum with RHO
already supplied.

This is a scoped obstruction, not a universal exclusion of coherent phase
measurements. The first missing source datum is a typed oriented evaluation
or coherence map from the Z6 phase fiber into End(H_F), together with an
observable that distinguishes rho from bar(rho) and is compatible with the
actual J_F, grading, faces, state and time evolution. The original source
must supply that map or an equivalent open-leg/interference insertion. It
cannot be obtained by placing a chosen Z6 scalar into the round product
Pi_triangle. Until that datum exists, Kstr fixes residue magnitudes while the
pi/3 phase remains a separate declared phase fiber rather than a measurable
observable of the given whole source.
