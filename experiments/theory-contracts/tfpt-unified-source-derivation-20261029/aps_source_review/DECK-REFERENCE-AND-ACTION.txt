2. FULL NORMAL REFLECTION: EXACT CONDITIONAL REF/REL

Use the SAME existing matrices and operator
  N=[[0,-1],[1,0]], Z=diag(1,-1), S=NZ,
  B_Phi=ZA-S tensor Phi, D_Phi=N(partial_r+B_Phi).
Normal matrices commute with the internal coefficient. N S=-Z, so
  D_Phi=D0+Z tensor Phi, D0=N(partial_r+ZA).

Let R_r pull back r to-r, and assume it preserves the tangential A after
the actual bundle/domain transport. Write Phi_tau(r,theta)=Phi(-r,theta).
For tau_S=S R_r, use
  S N S=-N, S Z S=-Z, R_r partial_r R_r=-partial_r.
Then exactly
  tau_S D_Phi tau_S^-1=D0-Z tensor Phi_tau,
  D_ref=D0+(Z/2) tensor(Phi-Phi_tau),
  D_rel=(Z/2) tensor(Phi+Phi_tau).                       (1)

For a constant or otherwise reflection-even Phi, (1) does give
  D_ref=D0, D_rel=Z tensor Phi=-N S tensor Phi.
Likewise a reflection-even variation at fixed tau and fixed A has V_ref=0.
This is a useful positive conditional identity. No change to the tangent
quarter alpha occurs in this local formula, because r reflection leaves A.

The omitted base reflection is crucial. For S acting ALONE,
  S D_Phi S=-N partial_r+NZA-Z tensor Phi,
  D_ref=NZA, D_rel=N partial_r+Z tensor Phi.              (2)
Already at Phi=0, (2) is not the claimed massless full Dirac reference.
Thus a calculation only on a Fourier coefficient B or an internal matrix
