1. Gegenprobe ohne J

   mit J (1, 0, Viertelfluss)  : netto 1, Geschwindigkeiten [1.], Kerngewichte [0.929]
   ohne J (1, 0, kein Fluss)   : netto 1, Geschwindigkeiten [1.], Kerngewichte [0.866]
   gewöhnlich (1, 1)           : netto 2, Geschwindigkeiten [1. 1.], Kerngewichte [0.863 0.863]
   nur J (0, 0, Viertelfluss)  : netto 0, Geschwindigkeiten [], Kerngewichte []
   Die Kritik hat recht: Die Modenzahl allein erzwingt J nicht.

2. Index als Windung von det M(phi) an den acht Impulsecken (m = 0,6, r_w = 1)

   (n+, n-) = (1, 0): Windung je Ecke [1, 0, 0, 0, 0, 0, 0, 0], mit Eckenchiralität gewichtet: Index 1
   (n+, n-) = (1, 1): Windung je Ecke [2, 0, 0, 0, 0, 0, 0, 0], mit Eckenchiralität gewichtet: Index 2
   (n+, n-) = (0, 0): Windung je Ecke [0, 0, 0, 0, 0, 0, 0, 0], mit Eckenchiralität gewichtet: Index 0
   (n+, n-) = (2, 0): Windung je Ecke [2, 0, 0, 0, 0, 0, 0, 0], mit Eckenchiralität gewichtet: Index 2
   ohne Wilson-Glied (W = 0 überall): Windung je Ecke [1, 1, 1, 1, 1, 1, 1, 1], gewichtet 0: Die Verdoppler heben sich auf.
   Der Index hängt nur an der Windung an der physischen Ecke, nicht am Viertelfluss. Was J leistet, ist
   etwas anderes: Mit J genügt ein einziges komplexes Massenfeld m e^{i theta} psi chi, dessen Phase um pi
   windet; dann ist die Masse selbst zweiwertig (Phi -> -Phi), das sind die zwei Blätter auf Bosonischem,
   und auf Fermionen wirkt mu4. Ohne J braucht die Konfiguration (1, 0) zwei unabhängige Majoranamassen
   und hat keine zwei Blätter. J wird also durch die Blattstruktur von P1 gewählt, nicht durch die Zählung.

3. Familien als chiraler Index der vier Marken D = mu4 auf CP^1

   h^0(K(D)) = h^0(O(2)) = 3, h^1 = 0: Index 3 (Riemann-Roch). Vierteldrehung: [(-1+0j), -1j, 1j]
   h^0(O(D)) = 5 (TFPTs Fünferträger). Vierteldrehung: [ 1.+0.j  0.+1.j -1.+0.j  0.-1.j  1.+0.j]
   Halbdrehung auf dem Träger: Eigenwerte {1: 3, -1: 2} -> Teilung 3 + 2
   Lambda^gerade C^5 = 1 + 10 + 5 = 16 (Spin(10)-Spinor einer Generation)
   Materie = H^0(K(D)) x Lambda^gerade H^0(O(D)): 48 Komponenten
   Spin-Dirac auf CP^1, gekoppelt an K^(1/2) x O(D) = O(3): ker D+ = H^0(O(2)) = 3, ker D- = 0.
   Dieselben vier Marken geben also den Fünferträger mit 3 + 2 und einen chiralen Familienindex 3 mit
   genau den Charakteren {-1, i, -i}, direkt aus z -> i z, ohne Spinstrukturen und ohne Wahl des Zentrums.

4. Twistgewicht h_R = N/16

   N =  8: c = 4, h_R = 1/2
   N = 16: c = 8, h_R = 1  -> Gewicht 1: 128 Spinorströme, 120 + 128 = 248
   N = 24: c = 12, h_R = 3/2
   N = 32: c = 16, h_R = 2
   N = 48: c = 24, h_R = 3
   Das wählt Blöcke aus 16 Majorana-Weyl Fermionen, also E8 je Block. Es entscheidet nicht zwischen einem
   und drei Blöcken (E8 hoch 3 hat je Block wieder h_R = 1), wohl aber gegen eine gemeinsame 48er-Summe.

5. Satzzahl: Gegenbeispiel aus der Kritik

   Unterraum 'alle Sätze tragen dasselbe Label' unter g: Eigenwerte [-1.+0.j  0.-1.j  0.+1.j]
   Der Unterraum ist invariant: True
   Die Kritik hat recht: Die Familiencharaktere schließen drei Sätze nicht aus. Die Behauptung aus Z8 ist
   zu stark und wird zurückgenommen. Unterscheiden könnte das Niveau eines gemeinsamen E8 Stroms (1 gegen 3).

6. Schleifenenergie E(R) = 2 pi sigma R + (h - c/24)/R, c = 8

   Ramond-Grundzustand (h = 1)       : Koeffizient von 1/R = +0.6667, Minimum bei R* = 1/sqrt(3 pi sigma)
   Vakuum (h = 0)                    : Koeffizient von 1/R = -0.3333, kein stabilisierender Term
   KMS-Zustand von H6 (<L0> = c/24)  : Koeffizient von 1/R = +0.0000, kein stabilisierender Term
   Im Zustand von H6 (Z4: <L0> = c/24 bei tau = i) verschwindet der Term; die Stabilisierung der Kritik
   verlangt den Ramond-Grundzustand und gilt dann für eine andere Zustandswahl.

   Schwelle der Kritik für ihr Zusatzmodell auf S^3: 2 - sqrt(8/3) = 0.3670 (nur Arithmetik geprüft;
   das Modell selbst liegt nicht vor).
