1.0 Grundlagen der Majoranadrehung
   Ginsparg-Wilson-Relation: Rest 8.9e-16. C D(k) C^-1 = D(-k)^T: Rest 0.0e+00.
   X = g5 (1 - D/2) ist hermitesch (Rest 0.0e+00) mit X^2 = 1 - D^+D/4 (Rest 3.3e-16).
   Die symmetrische Drehung lambda -> e^{i alpha X} lambda lässt die Majoranawirkung exakt invariant.
   Für Dirac-Felder gibt es die asymmetrische Drehung mit g5^ = g5 (1 - D), g5^2 = 1 (Z16). Für Majorana
   sind lambda und lambda-quer verbunden; übrig bleibt nur X, und X hat kein ganzzahliges Spektrum.
   |X| auf dem Gitter 8^4 (Mittelpunkte): 0.057 bis 0.914; |X| -> 1 an der physischen Ecke,
   |X| -> 0 an den Verdopplerecken (dort D = 2).
   Die Gitter-Vierteldrehung J = e^{i pi X/2} hat J^4 = e^{2 pi i X} != 1: max |J^4 - 1| = 2.000,
   auf 100 % der Gitterimpulse 8^4 über 0,01. J^4 = 1 gilt nur für k -> 0.
   Lokalität: Annäherung an die Verdopplerecke (pi,0,0,0) aus den vier Achsenrichtungen, Abstand 1e-2/1e-4:
   größte Differenz von X 1.4e-02/1.4e-04 (stetig), von sign X 2.83/2.83.
   sign X springt an den Verdopplerecken: Sein Ortsraumkern fällt nur wie eine Potenz, es ist nichtlokal.
   X ist analytisch (exponentiell lokal), weil D_W - rho keine Nullstelle hat.

Teil 2: Reflexionspositivität (OS) bei endlichem Gitterabstand, freies Feld, fester Raumimpuls p
   OS-Form für lineare Observablen F = sum_t psi-quer(t) f_t (t >= 1, Link) bzw. t >= 0 (Platz):
   M_st = -g4 S(1 - s - t) (Link), -g4 S(-s - t) (Platz); dazu die psi-Seite. RP <=> M >= 0.
   Das Vorzeichen ist eine Konvention der Form; es ist einmal an Wilson r = 1 festgelegt.

Urteil
   1a_phasenpotential: hergeleitet: flach (Spannweite < 1e-12) nur mit der Majoranadrehung X (lokal, nicht quantisiert, J^4 != 1) oder sign X (quantisiert, nichtlokal); die lokale eindeutige GJ-Form behält 0.0073 je Zelle mit Periode pi; Wilson 0.083 euklidisch, 0.0882 hamiltonsch
   1b_index: hergeleitet: eine chirale Majorana-Weyl-Mode je Paar (Index = Windung von eta_+) für X, Xq, GJ und Wilson; Verdoppler tragen beim Overlap nicht bei; AB-Viertelfluss nicht im Overlap enthalten
   1c_wand: gescheitert für lokale Formen, Lesart für Xq: wandfrei nur mit nichtlokaler Drehung (dF ~ 1/L); lokal-flach (X) wird der Schnitt zur Wand (Spannung 0.0063 gegen Wilson <= 0.151 je Einheit Wandquerschnitt), lokal-eindeutig (GJ) bleiben zwei pi-Wände (je <= 0.0160)
   2_positivitaet: hergeleitet (Zielkonflikt): Wilson r <= 1 Link-RP für jede Massenphase; freies Overlap bei theta = 0 Link-RP (Pol + positives Kontinuum), Lu-Shao dafür nicht reproduziert; flache gedrehte Formen (X, Xq) verletzen RP auf Gitterskala, auch für p -> 0; GJ bei pi/2 nicht reflexionssymmetrisch. Für H6: Wand oder Positivität
   3_gravitation: gescheitert: kein chiraler Regulator macht kappa bestimmter; Overlap ohne endlichen lokalen Hilbertraum, SLAC ohne Flächengesetz (+0.162 je Verdopplung), Hamilton-chiral = Wilson(r); a/l_P bleibt regulatorabhängig (Wilson r = 1: kappa = 0.2208 je Dirac)
