## What a new hypothesis must state

A scenario may introduce a rule that the record does not contain. The
rule is an explicit mathematical definition: an operator, a map, a weight
or a constraint written so that it can be programmed. It names the object
it acts on, what it fixes that P1, P2 and E8 leave open, at least two
anchor groups from the list above whose values it yields, and which
closed route it differs from and by which premise. A sentence that
restates the open problem is no rule.
